# 🫀 Digital 3D Heart Modelling

An AI-assisted medical imaging project for 3D cardiac reconstruction, cardiac feature extraction, and abnormality analysis from medical imaging data.

## 🚀 Features

- Cardiac image preprocessing
- Heart segmentation
- 3D heart reconstruction
- Cardiac feature extraction
- Septal defect screening
- Interactive 3D heart visualization
- Integrated Python backend and web interface

## 🛠️ Technologies

- Python
- PyTorch
- TensorFlow
- OpenCV
- NumPy
- React.js
- JavaScript
- Node.js
- Express.js
